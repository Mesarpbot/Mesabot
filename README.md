# MESA BOT
موقع ثابت يساعد إدارة MESA على البحث عن مواد OneState وتجهيز ردود التذاكر ونسخها إلى Discord.

## محتويات الحزمة
- `index.html` واجهة الموقع.
- `style.css` التصميم المتجاوب للهاتف والكمبيوتر.
- `app.js` البحث والاختيار وتجهيز الرد والنسخ.
- `data.json` قاعدة القوانين والتعليمات الداخلية.
- `rules.js` نسخة احتياطية/مقروءة من قاعدة القوانين.

## النشر المجاني على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub باسم `mesa-bot`.
2. ارفع **كل الملفات الموجودة داخل المجلد** إلى جذر المستودع، وليس المجلد كطبقة إضافية.
3. من المستودع افتح `Settings` ثم `Pages`.
4. تحت `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط `Save`.
6. بعد اكتمال النشر سيكون الرابط عادةً: `https://YOUR-USERNAME.github.io/mesa-bot/`.

## الاستخدام
افتح الموقع، ابحث بالكود أو الاسم، اضغط على مادة لإضافتها. يمكن اختيار أكثر من مادة. أدخل اسم اللاعب والإداري إن رغبت، ثم اضغط «نسخ الرد بالكامل» والصقه في Discord.

## ملاحظات مهمة
- الموقع مجاني ولا يحتاج اشتراكاً أو تسجيل دخول.
- هذه نسخة تجهيز ونسخ يدوي؛ لا ترسل رسائل تلقائياً إلى Discord ولا تحتاج Discord Bot Token.
- لا تضع أي Discord token أو مفتاح سري في ملفات الموقع العامة.
- راجع المصدر الرسمي وأحدث تحديثات القوانين قبل اعتماد أي عقوبة. التعليمات المصنفة MESA هي تعليمات داخلية منفصلة وليست قوانين عامة صادرة عن OneState.
- مصدر القوانين المدرج: https://chillbase.helpshift.com/hc/ar/3-onestate/faq/15-onestate-game-rules/?p=web/
